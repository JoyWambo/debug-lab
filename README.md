# Debug Lab

A React debugging laboratory project designed to teach debugging skills through intentional bugs in a product card application. This project simulates real-world issues and provides a comprehensive guide to identifying and fixing them.

## Getting Started

1. Install dependencies:

   npm install

2. Start the development server:

   npm start

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Product card component with intentional bugs
- Debugging guide with step-by-step fixes
- Before and after screenshots
- Comprehensive documentation in DEBUGGING.md

## Debugging

This lab includes three common React bugs for debugging practice.

### After Debugging

![After Screenshot](src/assets/images/After_Screenshot_2025-12-06%20224432.png)
